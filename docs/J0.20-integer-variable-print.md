# J0.20 — Affichage d'une variable INTEGER explicite avec PRINT

**Statut : livré, en revue Pilotage.** Base : main après PR #20 (J0.19) et PR #21 (documentation). Cœur natif C99 et hôte Linux exclusivement : aucun firmware ESP32 ni émulation Z80.

## Fonctionnalité

Le programme :

```basic
10 A%=2
20 PRINT A%
30 END
```

s'exécute par `RUN` / `:step` : affectation au magasin fourni par l'appelant, puis lecture par PRINT ; l'octet ASCII 2 (`0x32`) est suivi d'un LF (`0x0A`). L'alias `?A%` est déjà tokenisé en PRINT et suit le même chemin.

- Représentation CPC utilisée : marqueur `02`, deux octets de cache opaques, nom encodé avec bit 7 sur le dernier caractère. Les caches `20`, `EF` et autres valeurs importées ne sont ni modifiés ni interprétés comme des espaces.
- `bvb_read_explicit` (J0.17) effectue seul le décodage, la canonicalisation complète en majuscules et la recherche exacte par clé INTEGER dans `BasicVariableStore`. Les noms ont jusqu'à 40 caractères, avec chiffres et points.
- La lecture n'insère aucune valeur, ne change aucun ordre ni octet du magasin, ne modifie aucun octet du programme.
- Avec les API legacy sans magasin (`be_init`, `bsr_init`), l'exécution d'une lecture reste `BE_UNSUPPORTED`. Les types STRING (`03`) et REAL5 (`04`) ne sont pas exécutables.

## Conversion INTEGER

Le prototype Linux affiche en décimal signé les valeurs `int16_t` de -32768 à 32767, sans espace ni préfixe +, avec LF après chaque PRINT. La conversion élargit la magnitude en `int32_t` avant négation : le cas -32768 est défini en C99. Pas de `float`, `double`, `sprintf` ou allocation.

Il ne s'agit **pas** du formatage CPC historiquement validé. Les espaces, le traitement du signe positif, la largeur numérique, l'alignement et les conventions de colonnes restent à confronter à une référence CPC 6128.

## Diagnostic et atomicité

La variable absente produit `BE_VARIABLE_NOT_FOUND`, un **diagnostic interne**, sans valeur implicite inventée ni création d'entrée. L'initialisation implicite historique et les erreurs réellement produites sur CPC restent à étudier.

Traduction des erreurs `bvb_read_explicit` : `BVB_NOT_FOUND` → `BE_VARIABLE_NOT_FOUND` ; `BVB_TRUNCATED` → `BE_TRUNCATED` ; `BVB_INVALID_STORE` → `BE_INVALID_STORE` ; `BVB_OVERLAPPING_MEMORY` → `BE_OVERLAP` ; autres références invalides → `BE_BAD_SEQUENCE`.

L'exécuteur conserve la validation préalable du programme/magasin, les contrôles de chevauchement, la passe sans écriture qui mesure l'intégralité des sorties et la seconde passe conditionnée par la capacité. En échec, le buffer entier, `written`, le curseur, l'image du programme et le magasin restent identiques. Une ligne `PRINT "X":PRINT M%` doit échouer sans sortie si `M%` manque. Les affectations INTEGER sur lignes multistatement restent refusées.

## Tests et limites

Suite CTest n°17, `integer_variable_print` : affectations et réaffectations, valeurs limites, noms longs/casse, alias, caches non nuls, magasins corrompus, références tronquées/invalides, sorties trop petites, non-mutation bit à bit, API sans magasin, et non-régressions. Scénarios black-box CLI : programme témoin, alias, absent, séparation stdout BASIC/stderr pilote. Les 16 suites antérieures sont préservées ; build C99 strict avec `-Werror`, Linux standard et ASan/UBSan.

**[C]** Le désassemblage `basic.asm`, traitement des tokens `D033–D092`, établit l'existence de références scalaires dans le chemin de lecture d'expressions ; voir également les analyses J0.13–J0.17. **[D]** La lecture native par clé complète assure la cohérence interne de notre pipeline. **[V]** Les vecteurs restent dérivés de la ROM et synthétiques, non des captures CPC indépendantes : formatage, initialisations implicites et exactitude binaire restent à vérifier. **[B]** Expressions (`A%+3`), affectations depuis variable (`B%=A%`), arguments PRINT multiples, DEF*, STRING, REAL5 et tableaux sont exclus.

**J0.20 clôt le premier cycle élémentaire affectation/affichage, mais pas J0.** La suite prévue est l'évaluation d'expressions INTEGER pour le programme témoin défini dans `docs/ROADMAP_GATES.md`. Ne pas lancer J0.21 avant la revue Pilotage.
