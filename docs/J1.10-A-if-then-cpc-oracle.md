## Tokenisation RAM réellement mesurée

Pour la ligne `20 IF A% THEN 60`, les 17 octets observés avant RUN sont :

```text
11 00 14 00 A1 20 02 00 00 C1 20 EB 20 1E 3C 00 00
```

Interprétation bornée au corpus : `A1` est le token `IF`, `02 00 00 C1` la référence explicite `A%` avec cache opaque `00 00`, `EB` le token `THEN`, et `1E 3C 00` la référence de ligne 60 en entier 16 bits little-endian ; le `00` final termine l'enregistrement. Les caches ne sont pas des instructions. Le vérificateur contrôle ces octets **directement contre les RAM indépendantes archivées**, sans synthétiser une image « attendue » à partir du moteur C99.

## Intégrité, CI et frontière de J1.10-B

`tools/j1_10_if_then_verify.py` vérifie la provenance, tous les fichiers et tailles SHA, les 2/2 RAM/imprimante, les 14 signatures IF/THEN et les observations de flux, le manifeste indépendant et les empreintes épinglées. `--permanent --self-test` doit rejeter les falsifications sur copies temporaires (RAM, imprimante, LIST/PNG, source archivée, manifeste, sceau, faux HEAD). L'ancien corpus CPC J0/J1, les sources natifs et HW4 ne sont jamais modifiés.

**Frontière technique proposée, soumise à revue Pilotage uniquement :** `IF A% THEN 60` où `A%` est une référence INTEGER explicite existante et `60` un numéro de ligne littéral, condition fausse si zéro et vraie si non zéro ; chemin non pris = ligne suivante, chemin pris = ligne cible ou erreur 8/ERL de l'IF si cible absente ; aucune forme `ELSE`, `GOTO` explicite, comparaison, THEN-instruction, REAL ou STRING dans la première implémentation B proposée. Pas d'évaluateur d'expression générique, pas d'autre famille de contrôle.

L'atomicité d'une éventuelle implémentation C99 devra être testée **séparément**. Les sondes après RUN ne démontrent pas l'atomicité interne de la ROM CPC.

**CYD physique : `ON_DEVICE_UNVERIFIED`** (jalon oracle portable, sans flash requis). À compléter au HEAD final : CTest OFF/ON, contrôles historiques, permanence J1.10-A, trois images Xtensa ESP-IDF v5.5.6 sur **deux** projets, métriques mémoire, lien de PR et runs exacts. ### Limites de la preuve et décision

L'image RAM et les flux imprimante archivés sont indépendants du C99 ; leur reproduction ne prouve pas la compatibilité de toutes les variantes de IF. Le test STRING exploratoire observe `ERR=13 ERL=20` et reste hors B. Aucune assertion d'atomicité historique ROM n'est déduite des sondes `ERR/ERL`.

**Ce rapport est une remise développeur, non une acceptation Pilotage.** Le commit documentaire ultérieur doit repasser les contrôles affectés : ne pas confondre les runs de la révision de code avec le HEAD ultime. Statuts proposés : `CPC_ORACLE_VERIFIED`, `HOST_VERIFIED`, `TARGET_BUILD_VERIFIED`, `ON_DEVICE_UNVERIFIED`. J1.10-B et HW4 hors mandat, PR non fusionnée.
