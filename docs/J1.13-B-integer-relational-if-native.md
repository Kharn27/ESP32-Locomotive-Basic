# J1.13-B — Six relations INTEGER natives dans IF…THEN

**Mandat** : [issue #132](https://github.com/Kharn27/ESP32-Locomotive-Basic/issues/132). **Base** : `main@b91b33adf97aa54a9491b0e05587be02695647ef`.

## Frontière d'implémentation

Uniquement `IF <INTEGER% explicite> <relation> <INTEGER% explicite> THEN <ligne littérale>`, autonome. L'ancien `IF A% THEN ligne` est conservé. Les six tokens CPC observés par J1.13-A sont `= EF`, `<> F2`, `< F1`, `<= F3`, `> EE`, `>= F0`. La tokenisation reconnaît les opérateurs doubles avant leurs préfixes simples, conserve les espaces et émet les deux références `02 cache_low cache_high nom`. LIST reconstruit les symboles et les noms sans interpréter les caches. RUN lit deux variables INTEGER par la couche de binding, compare les `int16_t` signés sans calcul arithmétique, puis ne résout la cible que si la condition est vraie.

Exclus : ELSE, THEN instruction, GOTO après THEN, non-INTEGER, références implicites, comparaisons à constantes et expressions combinées, opérateurs relationnels dans d'autres instructions, format booléen CPC, matériel et écran.

## Provenance et différentiel

Oracle CPC6128 BASIC 1.1 acquis deux fois sous Caprice32 lors de J1.13-A, maintenu **immuable** sous `tests/fixtures/cpc6128/j1_13_integer_relations/`. Manifeste SHA256 `69ee185aa63fe6db1df8f6092af19df0a15dec70b991d918e8f99d2657a03070`. Les classifications historiques pré-B `UNSUPPORTED` restent intactes.

`tools/j1_13_b_native_verify.py` vérifie SHA des sources, manifeste, RAM originelle, imprimante originale ; compare **seulement le record complet IF ligne 30**, son en-tête, ses caches, ses espaces et son terminateur ; contrôle LIST et retokenisation. Les deux `PRINT #8` originaux sont transformés **uniquement en mémoire** selon `40 PRINT #8,420` → `40 PRINT 42` et `70 PRINT #8,810` → `70 PRINT 81`. Le stdout hôte est remappé 42↔420 et 81↔810 uniquement pour la trace de branche. Les octets de l'imprimante CPC ne sont **pas** prétendus égaux au stdout C99 ; **aucune comparaison de RAM intégrale adaptée** n'est effectuée.
