## Désassemblage et distinction unaire / binaire

Dans `basic.asm` 1.1, `D059` contient l'entrée `F5` qui dirige un moins **unaire** vers `D01D`; les routines `CF62–CFC5` et `D033` montrent que l'interprétation dépend du contexte d'expression. `F5` est également le token à rechercher **après A%** dans `B%=A%-n` ; il ne faut pas inventer un token « moins binaire » distinct. Le traitement unaire de `-32768` déjà authentifié est `F5 1F 00 00 00 00 90`, à distinguer du signe situé dans la seconde ligne.

Attentes indépendantes pour le suffixe de la ligne 20, avant le terminateur `00` : `F5 11` pour les cas à `-3`, `F5 0E` pour `-0`, `F5 0F` pour `-1`, `F5 19 FF` pour `-255`. Les tokens `0E..18` codent directement les petites constantes décimales. Ces signatures sont vérifiées contre la RAM CPC réellement extraite, **pas produites par le tokeniseur C99**.

**Lecture des canaux :** pour les cinq cas sans erreur, les captures `run.png` montrent la valeur affichée et `Ready`. Pour NMIN_M1, le PNG `run.png` montre littéralement **`Overflow in 20`**, puis `Ready`; la sonde imprimante direct-mode lit `ERR=6`, puis `B%=0`. Aucune comparaison brute écran / imprimante CPC / stdout C99 n'est déduite de ces chiffres.

Les six images CPC indépendantes ont confirmé la signature `F5` **après la référence INTEGER A%** dans la ligne 20, et, dans les deux cas NMIN, la signature unaire `F5 1F 00 00 00 00 90` de la ligne 10. Le collecteur a enregistré les six images `list.png` et six `run.png`, les fichiers de configuration/commandes, les flux imprimante et les sorties native. Le comparateur C99 a rejeté les six nouvelles formes à l'export, sans faux `MATCH_EXACT`. Il y a donc **6 observations CPC exploitables et 0 implémentation nouvelle**.

Le validateur permanent a réussi ses **dix mutations négatives ciblées** et le rejet d'une identité de checkout falsifiée sur la copie d'archive ; ses contrôles portent sur les données brutes et les SHA, non sur les seules transcriptions du manifeste. Le contrôle indépendant au HEAD final, notamment nouvelle réacquisition image + imprimante et toutes les CI, relève encore de la barrière de décision de Pilotage.

## Hypothèses ouvertes et proposition J1.3-B — interdit pour l'instant

La branche future, **si Pilotage autorise J1.3-B après revue**, pourrait implémenter uniquement une affectation INTEGER autonome `B%=A%-n` avec `0..255`, sans évaluateur général ni REAL5 supplémentaire. Observer d'abord le token `F5`, la limite `-32768`, l'atomicité et l'éventuel diagnostic du CPC au cas NMIN_M1. Le traitement exact du dépassement reste **non spécifié** avant preuve.

Les quatre B1 historiques autrefois `UNSUPPORTED`, les 18 comparaisons LIST/RUN historiques `UNVERIFIED` et l'absence de compatibilité CPC générale sont conservés.
